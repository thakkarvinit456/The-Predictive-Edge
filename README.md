## 📌 Overview

**The Predictive Edge** is a Machine Learning–based system that predicts the **Probability of Success (PoS)** of early-stage startups.

It analyzes multiple dimensions of startup performance and provides:

- 📊 Probability of Success Score (0–100)
- ⚠️ Risk Category Classification
- 🔍 Weakness Identification
- 📈 Strategic Recommendations

The goal is to transform startup funding from intuition-driven decisions to **data-driven predictive modeling**.

---

## 🎯 Problem Statement

Over **90% of startups fail**, primarily due to:

- Lack of market demand
- Weak team structure
- Poor funding management
- Absence of data-driven decision making

Current tools like SWOT analysis, surveys, and financial models are **descriptive** — they explain what happened but do not predict outcomes.

There is no unified AI-based engine combining:

- Team capability  
- Funding structure  
- Market validation  
- Industry momentum  
- Public sentiment  

This project addresses that gap.

## 🏗 System Architecture

```
Data Collection
        ↓
Data Cleaning & Preprocessing
        ↓
Feature Engineering
        ↓
Model Training (Random Forest)
        ↓
PoS Prediction
        ↓
Dashboard + Recommendations
```

---

## 📊 Model Workflow

1. Load startup dataset  
2. Split data (80% training / 20% testing)  
3. Train Random Forest Classifier  
4. Evaluate model accuracy  
5. Predict new startup success probability

## ▶️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/the-predictive-edge.git
cd the-predictive-edge
```

### 2. Create Virtual Environment (Recommended)

```bash
python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Flask Backend

```bash
python app.py
```

### 5. Open Frontend

Open `frontend/index.html` in your browser.
